LibrarySystem 📚

Sistema desktop de gerenciamento de biblioteca desenvolvido em Java.

Sobre o projeto

O LibrarySystem é uma aplicação desktop que permite administrar livros, cadastrar usuários e registrar empréstimos.

O projeto utiliza JavaFX para a interface gráfica e SQLite para armazenamento de dados.

Tecnologias utilizadas
Java 17+
JavaFX
SQLite
JDBC
Maven
SQL
Funcionalidades
Cadastro de livros.
Edição de livros.
Exclusão de livros sem histórico de empréstimos.
Pesquisa por título.
Cadastro de usuários durante empréstimos.
Registro de empréstimos.
Controle de disponibilidade.
Persistência de informações.
Como executar

Pré-requisitos:

JDK 17 ou superior.
Maven.

Execute o comando:

bash
mvn clean javafx:run
