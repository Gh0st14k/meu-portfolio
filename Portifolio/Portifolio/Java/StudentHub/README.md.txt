StudentHub 🎓

Sistema desktop de gerenciamento acadêmico desenvolvido em Java.

Sobre o projeto

O StudentHub permite cadastrar alunos, registrar notas, calcular médias e acompanhar o desempenho acadêmico.

Tecnologias utilizadas
Java
Java Swing
Programação Orientada a Objetos
Funcionalidades
Cadastro de alunos.
Registro de notas.
Cálculo automático de médias.
Identificação de aprovação e reprovação.
Exclusão de alunos.
Validação de informações.
Como executar

Compile:

bash
javac Main.java Student.java


Execute:

bash
java Main
