FinanceFlow 💰

Aplicação desktop de controle financeiro pessoal desenvolvida em Python.

Sobre o projeto

O FinanceFlow permite registrar receitas e despesas, acompanhar o saldo disponível e visualizar 
o histórico de movimentações financeiras.

Tecnologias utilizadas
Python
Tkinter
SQLite
SQL
Funcionalidades
Cadastro de receitas e despesas.
Organização por categorias.
Cálculo automático do saldo.
Listagem de movimentações.
Exclusão de registros.
Persistência de dados em SQLite.
Como executar
Instale o Python 3.
Clone este repositório.
Entre na pasta do projeto.
Execute:
bash
python main.py

Aprendizados

Este projeto trabalha conceitos de programação orientada a objetos, interfaces gráficas, operações 
CRUD, banco de dados relacionais e validação de dados.
