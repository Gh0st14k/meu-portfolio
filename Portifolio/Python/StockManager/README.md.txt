StockManager 📦

Sistema desktop de gerenciamento de estoque desenvolvido em Python.

Sobre o projeto

O StockManager é uma aplicação para gerenciamento de produtos, controle de quantidades e acompanhamento de níveis de estoque.

Tecnologias utilizadas
Python 3
Tkinter
SQLite
SQL
Funcionalidades
Cadastro de produtos.
Listagem de produtos.
Edição de informações.
Exclusão de produtos.
Pesquisa por nome.
Controle de quantidades.
Indicadores de estoque baixo.
Banco de dados SQLite.
Como executar
Instale Python 3.
Clone o repositório.
Entre na pasta do projeto.
Execute:
bash
python main.py

Estrutura técnica

O projeto utiliza programação orientada a objetos, interface gráfica com Tkinter e persistência de dados com SQLite.
